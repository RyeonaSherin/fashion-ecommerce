# LuxeWear

LuxeWear is a modern, multi-page fashion website built using HTML, CSS, and JavaScript. The project focuses on delivering a clean, responsive, and visually appealing user interface to showcase fashion collections, engage users, and provide basic interactive features.

This repository is intended as a frontend portfolio project and a foundation for future e-commerce functionality.

---

## Project Overview

LuxeWear is designed to simulate a fashion brand website with multiple pages, including a home page, collections, contact form, and login interface. The project emphasizes layout design, responsive behavior, and basic client-side interactions.

The website is fully static and runs directly in the browser without external frameworks.

---

## Features

- Fully responsive and mobile-friendly design
- Modern layout using CSS Flexbox and Grid
- Multi-page navigation structure
- Image gallery and category-based collections
- Add to Cart interaction using JavaScript alerts
- Contact form ready for backend integration
- Login and signup UI page

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, or similar)

### Installation

1. Clone the repository:
```
git clone https://github.com/mdasharaf07/LuxeWear.git
```

2. Navigate to the project directory.

---

## Usage

Open any HTML file (starting with `index.html`) in a web browser to explore the website.

No build tools or dependencies are required.

## Intended Use

- Frontend portfolio project
- UI/UX design practice for fashion or e-commerce websites

## Limitations

- Static website with no backend integration
- Add to Cart feature is UI-only
- No persistent user authentication or data storage
